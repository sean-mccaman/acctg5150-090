# Project 2: Unclaimed Property at Silicone Motors (ACCTG 6155, Fall 2026)

The guide, the counsel memo, and the data dictionary are on the Project 2 page:
https://seanmccaman.com/acctg6155/2026-fall/project-2/

This folder holds the files a notebook needs to fetch, because the course site blocks programmatic downloads.

- `project2_starter.ipynb`: the optional starter notebook. Open it in Colab from the Project 2 page, then File > Save a copy in Drive.
- `data/csv/`: every table as CSV. Money is integer cents; dates are YYYY-MM-DD.
- `data/p2_wallet.sqlite`: the same tables in one SQLite file.

Data build c14c2737ec6d. Silicone Motors and its records are fictional.
